# Voice

Voice features include:

- Join/leave voice channels.
- Mute and deafen.
- Push-to-talk.
- Voice activation.
- Input/output device settings.
- Voice normalization and echo cancellation settings.
- Remote voice packet receive/playback.
- Notification sound playback.

The voice runtime is split across `session/voice_runtime.rs`, `session/voice_state.rs`, and `services/voice.rs`.
