# Identity And Servers

## Identity

The client supports:

- New identity creation.
- Seed phrase display and confirmation.
- Seed phrase restoration.
- Private key import.
- Persistent local identity storage.

Identity primitives use BIP39 seed phrases and Ed25519 signing keys.

## Servers

Server flows include:

- Saved server selection.
- Server connection.
- Trust-on-first-use warnings.
- Server display name and address handling.
- Reconnect restoration.

Connected server information includes the local display name, role, and server identity state.
