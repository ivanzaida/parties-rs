# Notifications

Notification support includes built-in and custom MP3 sounds for events such as mentions, direct messages, moderation actions, stream changes, and connection state changes.

Settings control:

- Notification volume.
- Per-sound default/custom selection.
- Custom MP3 file paths.

The service layer uses `minimp3` for MP3 decoding and the voice/audio runtime for playback.
